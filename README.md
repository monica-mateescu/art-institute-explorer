# React + TypeScript Art Institute Explorer

This is a **demo project** built for learning purposes during a **Full-Stack Web Developer course**.  
The goal of the project is to practice building a modern frontend application using **React** and **TypeScript**, while working with external data.

The application allows users to browse and manage artworks from a museum collection in an intuitive interface.

---

## ✨ Features

- 🔍 Search artworks by keyword  
- 🖼️ Browse artworks in a paginated list  
- ⭐ Add artworks to your favorites (stored in **localStorage**)  
- ⚡ Responsive and clean UI  

---

## 🔗 Demo

Check out the live version of the project here: [Art Institute Explorer Live](https://art-institute-explorer.onrender.com)

## 🛠️ Technologies

- React  
- TypeScript  
- JavaScript (ES6+)  
- Tailwind CSS (with DaisyUI)  

---

## 🎯 Learning Objectives

- Working with React functional components and hooks  
- Using TypeScript in a React project  
- Fetching and handling data from a **REST API**  
- Implementing search and pagination  
- Managing favorite items in **localStorage**  
- Building reusable UI components
